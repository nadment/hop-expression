= BASE64_DECODE

Decodes a Base64-encoded string to a string.

== Syntax

----
BASE64_DECODE( input )
----

== Arguments

input:: A Base64-encoded string or binary expression.

== Returns

String

== Usage

* The decoded bytes are interpreted as a string in UTF-8.
* Raises an error naming the invalid symbol if the argument contains a character that is not in the Base64 alphabet.
* Raises an error naming the padding symbol `=` if it is followed by other characters.
* Raises an error if the argument is truncated, that is its last symbols do not form whole bytes.
* Returns NULL if the argument is NULL.

== Examples

----
BASE64_DECODE('QXBhY2hlIEhvcA==') returns 'Apache Hop'
----
