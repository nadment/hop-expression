= CONCAT, ||

Concatenates two or more strings, binaries or arrays into one.

== Syntax

----
CONCAT( string1, string2 [, string3... ] )
----

The xref:concat.adoc["||",role=op] operator provides alternative syntax.

----
string1 || string2 [ || ... ]
----

== Returns

String, Binary or Array

== Usage

* The arguments of another data type, such as a number or a boolean, are converted to string.
* If an argument is an array, the other arguments are added as elements to the array.
* NULL values are ignored.
* Returns NULL only if all arguments are NULL.

== Examples

----
CONCAT('AB','CD','12') returns 'ABCD12'
'AB' || 'CD' returns 'ABCD'
----
