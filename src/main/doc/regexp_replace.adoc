= REGEXP_REPLACE

Replaces the substrings of a string that match a regular expression pattern with a new string.

== Syntax

----
REGEXP_REPLACE( source, pattern [, replacement [, position [, occurrence [, parameters ] ] ] ] )
----

== Arguments

source:: The string to search.
pattern:: The regular expression pattern.
replacement:: The string that replaces the matched pattern. The default value is `''`, which removes the matched substrings.
position:: The position in source where the search starts. The default value is 1.
occurrence:: The occurrence of the pattern to replace. If 0 is specified, all occurrences are replaced. The default value is 0 (all occurrences).
parameters:: A string of one or more letters that indicate how the function matches the pattern.
* `c` Case-sensitive matching.
* `i` Case-insensitive matching.
* `m` Multi-line mode.
* `n` Allows the period (`.`), which is the match-any-character character, to match the newline character.

== Returns

String

== Usage

* The pattern is defined according to the Java language regular expression rules.
* The replacement can contain backreferences to capture groups, written as a backslash followed by the number of the group. A capture group is a regular expression enclosed within parentheses.
* If no match is found, the function returns source unchanged.
* An empty pattern matches nothing.
* Returns NULL if source, pattern or replacement is NULL.

== Examples

----
REGEXP_REPLACE('A1.2.3.4','[^0-9]') returns '1234'
REGEXP_REPLACE('ABC, ABC, ABC','ABC', 'EFG', 1, 2) returns 'ABC, EFG, ABC'
REGEXP_REPLACE('abc', '(a)(b)', '\2\1') returns 'bac'
----
