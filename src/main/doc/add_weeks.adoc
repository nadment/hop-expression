= ADD_WEEKS

Adds or subtracts a specified number of weeks to a date or timestamp.

== Syntax

----
ADD_WEEKS( date, weeks )
----

== Arguments

date:: The date or timestamp to modify.
weeks:: The number of weeks to add. A negative number subtracts weeks.

== Returns

Date

== Usage

* If weeks has a decimal part, it is truncated before the addition.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ADD_WEEKS(DATE '2019-01-15', 1) returns DATE '2019-01-22'
ADD_WEEKS(DATE '2019-01-15', -3) returns DATE '2018-12-25'
----
