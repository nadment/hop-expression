= SUBSTRING, SUBSTR

Returns the portion of a string that starts at the specified position, optionally limited to a number of characters.

== Syntax

----
SUBSTRING( string, start [, length ] )
----

The `SUBSTR` function is an alias.

----
SUBSTR( string, start [, length ] )
----

== Arguments

string:: The string from which the portion is extracted.
start:: The position of the first character to return.
length:: The number of characters to return.

== Returns

String

== Usage

* The first character of a string has position 1.
* If start is negative, counting begins at the end of the string.
* If length is not specified, all the characters to the end of the string are returned.
* If start is beyond the end of the string, or if length is zero or negative, an empty string is returned.
* Returns NULL if one of the arguments is NULL.

== Examples

----
SUBSTRING('TEST FROM',6) returns 'FROM'
SUBSTRING('TEST FROM',6,2) returns 'FR'
SUBSTRING('TEST FROM',1,4) returns 'TEST'
SUBSTRING('TEST FROM',-4) returns 'FROM'
----
