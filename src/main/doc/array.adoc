= ARRAY

Returns an array containing the values of the arguments.

== Syntax

----
ARRAY( [ expression1 [, expression2 [, ... ] ] ] )
----

The square brackets `[ ]` provide an alternative syntax.

----
[ expression1 [, expression2 [, ... ] ] ]
----

== Returns

Array

== Usage

* If the array is empty or all its elements are NULL, the result type is an array of type null.

== Examples

----
ARRAY(1,2,3) returns [1,2,3]
ARRAY() returns []
----
