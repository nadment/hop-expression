= CONTAINS

Checks whether a string or binary value contains another one.

== Syntax

----
CONTAINS( value, search )
----

== Returns

Boolean

== Usage

* If value is binary, search must be binary or a string converted to binary; otherwise both arguments are compared as strings.
* The comparison of strings is case-sensitive.
* Returns TRUE if search is empty.
* Returns TRUE if search is found inside value, FALSE otherwise.
* Returns NULL if one of the arguments is NULL.

== Examples

----
CONTAINS('TEST','ES') returns TRUE
CONTAINS('TEST','es') returns FALSE
CONTAINS(BINARY '1A2B3C4D5E6F',BINARY '2B3C') returns TRUE
CONTAINS(BINARY '1A2B3C4D5E6F',BINARY '0A2B') returns FALSE
----
