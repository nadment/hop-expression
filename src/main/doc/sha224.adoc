= SHA224

Calculates the SHA-224 hash of a value.

== Syntax

----
SHA224( value )
----

== Arguments

value:: The string or binary value to hash.

== Returns

String

== Usage

* The result is a hex-encoded string of 56 characters (224 bits).
* Returns NULL if the argument is NULL.

== Examples

----
SHA224('Test') returns 'c696f08d2858549cfe0929bb7b098cfa9b64d51bec94aa68471688e4'
----
