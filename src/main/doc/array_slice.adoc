= ARRAY_SLICE

Returns an array made of a subset of the elements of an array.

== Syntax

----
ARRAY_SLICE( array, from, to )
----

== Arguments

array:: The source array.
from:: The position of the first element to include. The first element of the array has position 0.
to:: The position of the element at which the subset ends. This element is not included.

== Returns

Array

== Usage

* A negative position is interpreted as an index from the back of the array.
* If both from and to are beyond the upper or lower end of the array, the result is an empty array.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ARRAY_SLICE([1,2,3,4,5,6],0,2) returns [1,2]
ARRAY_SLICE(['FOO','APACHE','HOP','BAR'], 1, 3) returns ['APACHE','HOP']
ARRAY_SLICE([0,1,2,3,4,5,6], -5, -3) returns [2,3]
ARRAY_SLICE([0,1,2,3,4,5,6], 0, 2)
----
