= STRING_ENCODE

Encodes the special characters of a string with the Java string literal format.

== Syntax

----
STRING_ENCODE( string )
----

== Returns

String

== Usage

* The escape sequences are `+\b+`, `+\t+`, `+\n+`, `+\f+`, `+\r+`, `+\"+`, `+\\+` and `+\u+` followed by the hexadecimal code of a Unicode character.
* Returns NULL if the argument is NULL.

== Examples

----
STRING_ENCODE('€') returns '\u20AC'
----
