= XOR

Returns TRUE if one of the two boolean expressions is TRUE, but not both.

== Syntax

----
boolean1 XOR boolean2
----

== Returns

Boolean

== Usage

* A number is converted to a boolean: 0 is FALSE and any other value is TRUE. Other data types like a string raise an error.
* Returns NULL if one of the arguments is NULL.
