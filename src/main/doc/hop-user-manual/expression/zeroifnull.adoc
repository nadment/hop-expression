= ZEROIFNULL

Returns 0 if the argument is NULL; otherwise, returns the argument.

== Syntax

----
ZEROIFNULL( numeric )
----

== Returns

The data type of the returned value is the data type of the argument.

== Usage

* The argument must be an expression that evaluates to a numeric value or NULL.

== Examples

----
ZEROIFNULL(1) returns 1
ZEROIFNULL(1.1) returns 1.1
----
