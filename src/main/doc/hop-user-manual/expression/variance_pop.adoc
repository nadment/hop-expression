= VARIANCE_POP [aggregate]

Returns the population variance of the non-null values over a group of rows.

== Syntax

----
VARIANCE_POP( expression )
----

== Returns

Number

== Usage

* The result is the sum of the squares of the differences between expression and the mean of expression, divided by the number of non-null values:
+
----
(SUM( expression * expression ) - SUM( expression ) * SUM( expression ) / COUNT( expression )) / COUNT( expression )
----
* NULL values are ignored.

NOTE: This is an aggregate function that should only be used in the Aggregate transform.
