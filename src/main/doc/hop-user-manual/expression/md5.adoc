= MD5

Calculates the MD5 hash of a value.

== Syntax

----
MD5( value )
----

== Arguments

value:: The string or binary value to hash.

== Returns

String

== Usage

* The result is a hex-encoded string of 32 characters (128 bits).
* A string is hashed in UTF-8, and a value of another data type, such as a number or a date, is hashed as its text.
* Returns NULL if the argument is NULL.

== Examples

----
MD5('Test') returns '0cbc6611f5540bd0809a388dc95a615b'
----
