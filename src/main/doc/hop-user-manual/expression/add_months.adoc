= ADD_MONTHS

Adds or subtracts a specified number of months to a date or timestamp.

== Syntax

----
ADD_MONTHS( date, months )
----

== Arguments

date:: The date or timestamp to modify.
months:: The number of months to add. A negative number subtracts months.

== Returns

Date

== Usage

* If months has a decimal part, it is truncated before the addition.
* If the resulting month has fewer days than the day component of date, the result is the last day of the resulting month. Otherwise, the result has the same day component as date.
* A year beyond 9999 is supported, but a result out of the supported range of dates raises an error.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ADD_MONTHS(DATE '2019-01-15', 1) returns DATE '2019-02-15'
ADD_MONTHS(DATE '2019-01-31', 1) returns DATE '2019-02-28'
----
