= ARRAY_DISTINCT

Returns an array without the duplicate elements of an array.

== Syntax

----
ARRAY_DISTINCT( array )
----

== Arguments

array:: The source array.

== Returns

Array

== Usage

* The first occurrence of each element is kept, in the original order of the array.
* Elements are compared by value.
* The NULL elements are duplicates of each other, only the first one is kept.
* Returns NULL if the array is NULL.

== Examples

----
ARRAY_DISTINCT([1,2,1,3,2]) returns [1,2,3]
ARRAY_DISTINCT(['b','a','b']) returns ['b','a']
ARRAY_TO_STRING(ARRAY_DISTINCT(STRING_TO_ARRAY('b,a,b,c',',')),',') returns 'b,a,c'
----
