= ARRAY_CONCAT

Returns a new array with the elements of two or more arrays.

== Syntax

----
ARRAY_CONCAT( array1 [, array2... ] )
----

== Arguments

array1, array2:: The arrays to concatenate.

== Returns

Array

== Usage

* The data types of the elements of the arrays must be compatible, the result is an array of their most general data type.
* With a single argument, the function returns the argument.
* NULL values are ignored.
* Returns NULL only if all arguments are NULL.

== Examples

----
ARRAY_CONCAT([1,2,3],[4,5]) returns [1,2,3,4,5]
ARRAY_CONCAT(['sun','mon'],['tue'],['wed']) returns ['sun','mon','tue','wed']
----
