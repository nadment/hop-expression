= ARRAY_REMOVE

Returns an array without all the elements equal to a value.

== Syntax

----
ARRAY_REMOVE( array, element )
----

== Arguments

array:: The source array.
element:: The value of the elements to remove.

== Returns

Array

== Usage

* The data type of element must be compatible with the data type of the elements of array.
* Elements are compared by value.
* A NULL element of the array never matches and is kept.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ARRAY_REMOVE([1,2,1,3],1) returns [2,3]
ARRAY_REMOVE(['a','b','a'],'a') returns ['b']
ARRAY_TO_STRING(ARRAY_REMOVE(STRING_TO_ARRAY('a,,b,',','),''),',') returns 'a,b'
----
