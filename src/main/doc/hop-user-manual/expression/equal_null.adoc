= EQUAL_NULL

Checks whether two expressions are equal. The comparison is NULL-safe, meaning that NULL is treated as a known value.

== Syntax

----
EQUAL_NULL( expression1, expression2 )
----

== Returns

Boolean

== Usage

* Returns TRUE if both arguments are NULL.
* Returns FALSE if only one of the arguments is NULL.

TIP: This is different from the equal comparison operator xref:equal.adoc["=",role=op], which treats NULL as an unknown value.

== Examples

----
EQUAL_NULL(DATE '2019-01-01',DATE '2019-01-01') returns TRUE
EQUAL_NULL(DATE '2019-01-01',DATE '2018-01-01') returns FALSE
----
