= DIV0

Divides the first numeric value by the second one like the division operator `/`, but returns 0 if the divisor is 0.

== Syntax

----
DIV0( dividend, divisor )
----

== Returns

Number

== Usage

* Returns 0 rather than raising an error if divisor is 0.
* Returns NULL if one of the arguments is NULL.

== Examples

----
DIV0(6,0) returns 0
DIV0(10,4) returns 2.5
----
