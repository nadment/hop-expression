= YEARS_BETWEEN

Returns the number of complete years between two dates.

== Syntax

----
YEARS_BETWEEN( date1, date2 )
----

== Arguments

date1:: The start date.
date2:: The end date.

== Returns

Integer

== Usage

* The result is negative if date2 is earlier than date1.
* Returns NULL if one of the arguments is NULL.

== Examples

----
YEARS_BETWEEN(TIMESTAMP '2001-01-01 12:00:00',TIMESTAMP '2000-01-01 00:00:00') returns -1
----
