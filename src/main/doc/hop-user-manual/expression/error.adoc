= ERROR

Raises an error with the given message and aborts the execution of the pipeline or workflow.

== Syntax

----
ERROR( message )
----

== Arguments

message:: The error message. A value of another data type is converted to a string. A NULL message raises an error with an empty message.

== Returns

This function never returns a value; it always raises an error.

== Usage

* Use `ERROR` within a `CASE` expression to set rules for aborting a pipeline.

== Examples

----
CASE value WHEN 1 THEN 'Flag 1' WHEN 2 THEN 'Flag 2' ELSE ERROR('Unsupported value') END
----
