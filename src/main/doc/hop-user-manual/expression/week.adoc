= WEEK

Returns the aligned week of the year of a date, where week 1 starts on the first day of the year.

== Syntax

----
WEEK( date )
----

== Returns

Integer between 1 and 53

== Usage

* Equivalent to xref:extract.adoc["EXTRACT",role=fun](WEEK FROM date).
* Returns NULL if the argument is NULL.

== Examples

----
WEEK(DATE '2015-12-31') returns 53
WEEK(DATE '2015-01-01') returns 1
----
