= GAMMA

Returns the value of the gamma function Γ(x), which extends the factorial to real numbers.

== Syntax

----
GAMMA( numeric )
----

== Returns

Number

== Usage

* For a positive integer n, `GAMMA(n)` returns the factorial of n-1, for example `GAMMA(5)` returns 24.
* For another value, the result has 32 significant digits.
* Raises an error for zero and the negative integers, where the gamma function is undefined, for example `GAMMA(0)` or `GAMMA(-1)`.
* Raises an error if the integer part of the result exceeds the maximum precision of a number, for an argument from 35, or near zero or a negative integer, for example `GAMMA(35)` or `GAMMA(1e-40)`.
* Returns NULL if the argument is NULL.

== Examples

----
GAMMA(1) returns 1
GAMMA(5) returns 24
GAMMA(0.5) returns 1.7724538509055160272981674833411
GAMMA(-1.5) returns 2.3632718012073547030642233111215
----
