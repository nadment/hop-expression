= UNICODE

Returns the Unicode code point of the first character of a string.

== Syntax

----
UNICODE( string )
----

== Returns

Integer

== Usage

* Returns 0 if the string is empty.
* Returns NULL if the argument is NULL.

== Examples

----
UNICODE('é') returns 233
UNICODE('€') returns 8364
UNICODE('') returns 0
----
