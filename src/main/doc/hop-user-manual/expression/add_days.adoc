= ADD_DAYS

Adds or subtracts a specified number of days to a date or timestamp.

== Syntax

----
ADD_DAYS( date, days )
----

The `+` and `-` operators provide an alternative syntax to add or subtract days.

----
date { + | - } days
----

== Arguments

date:: The date or timestamp to modify.
days:: The number of days to add. A negative number subtracts days.

== Returns

Date

== Usage

* If days has a decimal part, it is truncated before the addition.
* A year beyond 9999 is supported, but a result out of the supported range of dates raises an error.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ADD_DAYS(DATE '2019-01-15', 1) returns DATE '2019-01-16'
ADD_DAYS(DATE '2019-01-15', -20) returns DATE '2018-12-26'
ADD_DAYS(DATE '2022-05-24', -4) returns DATE '2022-05-20'
DATE '2022-05-24' - 4 returns DATE '2022-05-20'
----
