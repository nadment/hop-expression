= GREATEST

Returns the largest value among the arguments, ignoring NULL values.

== Syntax

----
GREATEST( expression1 [, expressionN... ] )
----

== Returns

The data type of the returned value is the common data type of the arguments.

== Usage

* All arguments must have compatible data types that can be ordered.
* NULL values are ignored.
* Returns NULL only if all arguments are NULL.

== Examples

----
GREATEST(5,2,9,4) returns 9
GREATEST('B','A','C') returns 'C'
----
