= RTRIM

Returns the string with trailing characters removed.

== Syntax

----
RTRIM( string [, characters ] )
----

== Arguments

string:: The string expression to trim.
characters:: One or more characters to remove from the right side, specified in any order. If omitted, the function removes whitespace characters.

== Returns

String

== Usage

* The whitespace characters are the Java whitespace characters, which do not include the no-break space `CHR(160)`.
* Returns NULL if one of the arguments is NULL.

== Examples

----
RTRIM(' a ') returns ' a'
RTRIM('012ABC10', '012') returns '012ABC'
----
