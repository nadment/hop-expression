= JSON_VALUE

Extracts a scalar value from a JSON value by using the JsonPath query language.

== Syntax

----
JSON_VALUE( json, path [ RETURNING type ] )
----

== Arguments

json:: JSON value or a JSON-formatted string.
path:: A xref:jsonpath.adoc[JsonPath] expression that identifies the value that you want to get.
type:: Data type of the returned value: `STRING`, `BOOLEAN`, `INTEGER`, `NUMBER` or `BINARY`. The default is `STRING`.

== Returns

The data type of the returned value is the one given by the `RETURNING` clause, String by default.

== Usage

* The path must begin with a dollar sign `$`, which represents the root.
* If the path does not match a value, NULL is returned.
* Returns NULL if json or path is NULL.

include::jsonpath.adoc[]

== Examples

----
JSON_VALUE('{"language":["English", "French"]}','$.language[1]') returns 'French'
JSON_VALUE('{"address":{"zip":"12345","city":"Brussels"}}','$.address.zip') returns '12345'
JSON_VALUE('{"name":"Smith", "age":29}','$.age' RETURNING INTEGER) returns 29
JSON_VALUE(FIELD_JSON, '$..book.length()')
JSON_VALUE('[{"id":123,"similarity":0.95}]',CHR(36)||'[0].similarity')
----
