= EXISTS

Returns whether a lambda condition is TRUE for at least one element of an array.

== Syntax

----
EXISTS( array, parameter -> condition )
----

== Arguments

array:: The source array.
parameter -> condition:: A xref:expression.adoc#lambda[lambda] evaluated for each element of the array, the parameter is the element.

== Returns

Boolean.

== Usage

* Returns TRUE if the condition is TRUE for at least one element.
* Otherwise, returns NULL if the condition is NULL for at least one element.
* Otherwise, returns FALSE, also if the array is empty.
* Returns NULL if the array is NULL.

== Examples

----
EXISTS([1,2,3], x -> x > 2) returns TRUE
EXISTS([1,2,3], x -> x > 5) returns FALSE
EXISTS([0,NULL,2,3,NULL], x -> x IS NULL) returns TRUE
EXISTS([1,NULL,3], x -> x > 5) returns NULL
EXISTS(STRING_TO_ARRAY('a,,b',','), s -> s = '') returns TRUE
----
