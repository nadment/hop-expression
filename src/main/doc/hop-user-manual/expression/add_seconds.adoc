= ADD_SECONDS

Adds or subtracts a specified number of seconds to a date or timestamp.

== Syntax

----
ADD_SECONDS( timestamp, seconds )
----

== Arguments

timestamp:: The date or timestamp to modify.
seconds:: The number of seconds to add. A negative number subtracts seconds.

== Returns

Date, or timestamp if the date is a timestamp, with its time zone

== Usage

* If seconds has a decimal part, it is truncated before the addition.
* A year beyond 9999 is supported, but a result out of the supported range of dates raises an error.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ADD_SECONDS(DATE '2024-02-18', 4) returns DATE '2024-02-18 00:00:04'
ADD_SECONDS(TIMESTAMP '2024-02-18 22:58:59', 2) returns TIMESTAMP '2024-02-18 22:59:01'
ADD_SECONDS(TIMESTAMP '2024-02-18 23:59:30', 45) returns TIMESTAMP '2024-02-19 00:00:15'
ADD_SECONDS(TIMESTAMP '2024-02-18 22:58:59', -60) returns TIMESTAMP '2024-02-18 22:57:59'
ADD_SECONDS(TIMESTAMP '2024-02-18 22:58:59', 1.9) returns TIMESTAMP '2024-02-18 22:59:00'
----
