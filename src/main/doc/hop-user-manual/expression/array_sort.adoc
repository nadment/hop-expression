= ARRAY_SORT

Returns an array with the elements of an array sorted in ascending or descending order.

== Syntax

----
ARRAY_SORT( array [, ascending ] )
----

== Arguments

array:: The source array.
ascending:: Optional boolean, TRUE to sort in ascending order (default), FALSE to sort in descending order.

== Returns

Array

== Usage

* The elements of the array must be of a type that can be ordered.
* The NULL elements are placed at the end of the array, whatever the order.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ARRAY_SORT([3,1,2]) returns [1,2,3]
ARRAY_SORT([3,1,2],FALSE) returns [3,2,1]
ARRAY_SORT(['mon','tue','fri']) returns ['fri','mon','tue']
----
