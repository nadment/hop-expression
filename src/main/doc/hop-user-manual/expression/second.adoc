= SECOND

Returns the second component of the specified timestamp.

== Syntax

----
SECOND( { date | timestamp } )
----

== Returns

Integer between 0 and 59

== Usage

* Equivalent to xref:extract.adoc["EXTRACT",role=fun]( SECOND FROM timestamp ).
* A date without time returns 0.
* Returns NULL if the argument is NULL.

== Examples

----
SECOND(TIMESTAMP '2019-01-01 15:28:59') returns 59
----
