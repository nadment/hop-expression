= MODE [aggregate]

Returns the most frequent value over a group of rows.

== Syntax

----
MODE( expression )
----

== Arguments

expression:: An expression of any data type.

== Returns

The data type of the expression.

== Usage

* NULL values are ignored, even if they are the most frequent.
* If several values have the same highest frequency, the first one met in the group is returned.
* Returns NULL if the group has no value other than NULL.
* All the distinct values of the group are kept in memory to count their occurrences.

NOTE: This is an aggregate function that should only be used in the Aggregate transform.

== Examples

----
MODE( Country )
----
