= TRUNC[ATE]

Truncates a numeric value to an integer or to the specified number of decimal places.

== Syntax

----
TRUNCATE( numeric [, scale ] )
----

The `TRUNC` function is an alias.

----
TRUNC( numeric [, scale ] )
----

== Arguments

numeric:: The numeric value to truncate.
scale:: The number of digits to keep after the decimal point. If not specified, the default is 0. A negative scale truncates the digits to the left of the decimal point.

== Returns

Number

== Usage

* Truncation is performed towards 0, not towards the smaller number. For example, `TRUNCATE(-9.6)` returns -9, not -10.
* Returns NULL if one of the arguments is NULL.

== Examples

----
TRUNCATE(28.52) returns 28
TRUNCATE(28.52, 1) returns 28.5
TRUNCATE(28.52, -1) returns 20
----
