= ARRAY_SLICE

Returns an array made of a subset of the elements of an array.

== Syntax

----
ARRAY_SLICE( array, from, to )
----

== Arguments

array:: The source array.
from:: The position of the first element to include. The first element of the array has position 1.
to:: The position of the last element to include.

== Returns

Array

== Usage

* The positions are the ones of xref:element_at.adoc["[\]",role=op] and xref:array_position.adoc["ARRAY_POSITION",role=fun]: the first element has position 1.
* A negative position is counted from the end of the array, -1 is the last element.
* If the position to is before the position from, the result is an empty array.
* If both from and to are beyond the upper or lower end of the array, the result is an empty array.
* If only one of from and to is beyond the end of the array, the result keeps the elements inside the array.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ARRAY_SLICE([1,2,3,4,5,6],1,2) returns [1,2]
ARRAY_SLICE(['FOO','APACHE','HOP','BAR'], 2, 3) returns ['APACHE','HOP']
ARRAY_SLICE([10,20,30,40], 2, -1) returns [20,30,40]
ARRAY_SLICE([10,20,30,40], -2, -1) returns [30,40]
ARRAY_SLICE([10,20,30,40], 3, 10) returns [30,40]
----
