= ENDSWITH

Checks whether a string or binary value ends with the specified suffix.

== Syntax

----
ENDSWITH( value, suffix )
----

== Returns

Boolean

== Usage

* Value and suffix must be strings or binaries, other data types are not accepted.
* If value is binary, a string suffix is converted to binary; if value is a string, a binary suffix is converted to string.
* The comparison of strings is case-sensitive.
* Returns TRUE if value ends with suffix, FALSE otherwise.
* Returns TRUE if suffix is empty.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ENDSWITH('TEST FROM','ROM') returns TRUE
ENDSWITH('TEST FROM','ROMA') returns FALSE
ENDSWITH(BINARY 'FAA12345',BINARY '2345') returns TRUE
ENDSWITH(BINARY 'FAA12345',BINARY '88') returns FALSE
ENDSWITH(BINARY '616263','c') returns TRUE
----
