= AGE

Returns the interval between two dates, in years, months and days rather than in days only.

== Syntax

----
AGE( date1, date2 )
AGE( date )
----

== Arguments

date1:: The date or timestamp to subtract from.
date2:: The date or timestamp to subtract.
date:: The date or timestamp to subtract from the current date at midnight.

== Returns

Interval

== Usage

* The result is computed field by field: the years, months, days, hours, minutes and seconds of date2 are subtracted from those of date1. A negative field borrows from the next field, a borrowed month has the number of days of the month of the earlier date.
* `AGE(date)` subtracts the date from the current date at midnight, `AGE(CURRENT_DATE, date)`, so the age of a birth date has no time part.
* The result is negative if date1 is earlier than date2.
* The fields of a timestamp are in its time zone, date2 is converted to the time zone of date1. A date without time zone is in the time zone of the system.
* Returns NULL if one of the arguments is NULL.

== Examples

----
AGE(DATE '2024-03-15', DATE '1980-06-23') returns INTERVAL '+43-8 22 00:00:00'
AGE(TIMESTAMP '2024-01-01 08:00:00', TIMESTAMP '2023-12-31 20:30:00') returns INTERVAL '+0-0 0 11:30:00'
AGE(DATE '1980-06-23', DATE '2024-03-15') returns INTERVAL '-43-8 22 00:00:00'
AGE(DATE '1980-06-23') returns the age at the current date
----
