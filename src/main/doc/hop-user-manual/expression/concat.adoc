= CONCAT, ||

Concatenates two or more strings or binaries into one.

== Syntax

----
CONCAT( string1 [, string2... ] )
----

The xref:concat.adoc["||",role=op] operator provides alternative syntax.

----
string1 || string2 [ || ... ]
----

== Returns

String or Binary

== Usage

* The arguments of another data type, such as a number, a boolean or a date, are converted to string.
* With a single argument, the function returns the argument.
* If an argument is a binary, the result is a binary and the other arguments must be binaries or strings.
* NULL values are ignored.
* Returns NULL only if all arguments are NULL.

== Examples

----
CONCAT('AB','CD','12') returns 'ABCD12'
'AB' || 'CD' returns 'ABCD'
----
