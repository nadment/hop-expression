= NULLIF

Returns NULL if the two expressions are equal, otherwise returns the first expression.

== Syntax

----
NULLIF( expression1, expression2 )
----

== Returns

The data type of the returned value is the same as the data type of expression1.

== Usage

* Both expressions must have the same (or compatible) data type.
* Returns NULL if expression1 is NULL.

== Examples

----
NULLIF(1,1) returns NULL
NULLIF(1,2) returns 1
NULLIF('TEST','XXX') returns 'TEST'
NULLIF(1,NULL) returns 1
----
