= ARRAY_TO_STRING

Converts an array to a string by casting each element to a string and concatenating them with a separator.

== Syntax

----
ARRAY_TO_STRING( array, separator )
----

== Arguments

array:: The array of elements to convert to a string.
separator:: The string to put between each element.

== Returns

String

== Usage

* Each element is converted to a string as the xref:cast.adoc["CAST",role=fun] function does.
* A NULL element of the array is converted to an empty string in the result.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ARRAY_TO_STRING(['Hello','world'],' ') returns 'Hello world'
ARRAY_TO_STRING([1.2,4,8+2],',') returns '1.2,4,10'
----
