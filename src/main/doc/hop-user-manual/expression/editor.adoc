= Expression editor

The expression editor helps to write an expression.
Open it with the button next to an expression in the dialog of a transform or an action; the xref:../pipeline/transforms/where.adoc[Where] transform shows it directly.

== Tree of the elements

* Lists the *Fields* (or the *Arguments* of a xref:udf.adoc[user-defined function]), the *Operators* and functions by category, and the *Variables*.
* Double-click an element, or right-click it and choose *Help*, to show its documentation.
* Drag an element into the text to insert it, like `"MY FIELD"`, `UPPER()` or `${PATH}`.

== Writing

* Syntax highlighting, adapted to the dark mode.
* Errors underlined a short time after typing, with their message on hover.
* Box around the bracket matching the one next to the caret.
* Double-click selects a word, a quoted identifier or a variable `${NAME}`.
* kbd:[Ctrl+/] comments or uncomments the lines with `//`.

== Completion

* kbd:[Ctrl+Space] completes a field, a function or a reserved word; a function is inserted with its parentheses, like `LEFT()`.
* `$` opens the list of the variables, also in a string or a comment.
* A single matching proposal is inserted without opening the list.

== Information

* Hover a function to read its description, a field to read its data type, a variable to read its value.
* kbd:[Ctrl]+click a function to show its documentation.

== Shortcuts

On macOS, use kbd:[Cmd] instead of kbd:[Ctrl].

[cols="1,2"]
|===
|Shortcut |Action

|kbd:[Ctrl+Space] |Complete
|kbd:[Ctrl+/] |Comment or uncomment, also kbd:[Ctrl+Shift+C]
|kbd:[Ctrl+Z] / kbd:[Ctrl+Shift+Z] |Undo / Redo
|kbd:[Ctrl+F] / kbd:[Ctrl+H] |Find / Replace
|kbd:[Ctrl+A] |Select all
|kbd:[Ctrl+C] / kbd:[Ctrl+X] / kbd:[Ctrl+V] |Copy / Cut / Paste
|===

The toolbar button *Evaluate or simplify expression* shows the optimized expression, like `2+3` simplified to `5`.
