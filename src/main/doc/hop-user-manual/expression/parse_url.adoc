= PARSE_URL

Returns the specified part of the URL or the value for the specified QUERY key.

== Syntax

----
PARSE_URL( url, part [, key ] )
----

== Arguments

url:: The URL to parse.
part:: The part of the URL to return.
* `HOST`
* `PORT`
* `PATH`
* `QUERY`
* `REF`
* `PROTOCOL`
* `AUTHORITY`
* `FILE`
* `USERINFO`
key:: The key of the query parameter whose value is returned, only with the `QUERY` part.

== Returns

String

== Usage

* The part is not case-sensitive: `PARSE_URL(url,'host')` is the same as `PARSE_URL(url,'HOST')`.
* Raises an error if part is not one of the allowed values, like `PARSE_URL(url,'HOSTNAME')`.
* Returns NULL if the URL does not have the requested part, for example the port of `'https://hop.apache.org/path'`.
* Returns NULL if url is not a valid URI reference, for example if it contains a space.
* A relative reference without protocol is accepted: `PARSE_URL('abc','PATH')` returns 'abc'.
* The `FILE` part is the path followed by the query.
* The values are returned as they are written in the URL, the percent-encoded characters are not decoded: use xref:url_decode.adoc["URL_DECODE",role=fun] to decode them.
* With a key, the function returns the value of this parameter of the query. The key is case-sensitive, and if it appears several times in the query, the first value is returned.
* Returns NULL if the key is not found in the query, or if the key is used with another part than `QUERY`.
* Returns NULL if one of the arguments is NULL.

== Examples

----
PARSE_URL('https://hop.apache.org:80/path?id=1','HOST') returns 'hop.apache.org'
PARSE_URL('https://hop.apache.org:80/path?id=1','PATH') returns '/path'
PARSE_URL('https://hop.apache.org:80/path?id=1&lang=fr','FILE') returns '/path?id=1&lang=fr'
PARSE_URL('https://hop.apache.org:80/path?id=1&lang=fr','QUERY') returns 'id=1&lang=fr'
PARSE_URL('https://hop.apache.org:80/path?id=1&lang=fr','QUERY','id') returns '1'
PARSE_URL('https://hop.apache.org:80/path?query=1#fragment','REF') returns 'fragment'
----
