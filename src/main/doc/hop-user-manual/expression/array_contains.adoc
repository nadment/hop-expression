= ARRAY_CONTAINS

Checks whether an array contains the specified element.

== Syntax

----
ARRAY_CONTAINS( array, element )
----

== Arguments

array:: The array to search.
element:: The element to search for within the array.

== Returns

Boolean

== Usage

* The data type of element must be compatible with the data type of the elements of array.
* A NULL element of the array never matches.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ARRAY_CONTAINS([1,2,3],2) returns TRUE
ARRAY_CONTAINS([1,2,3],0) returns FALSE
----
