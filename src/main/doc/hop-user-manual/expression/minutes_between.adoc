= MINUTES_BETWEEN

Returns the number of complete minutes between two timestamps.

== Syntax

----
MINUTES_BETWEEN( timestamp1, timestamp2 )
----

== Returns

Integer

== Usage

* Only complete minutes are counted: `MINUTES_BETWEEN(TIMESTAMP '2019-01-01 15:00:59',TIMESTAMP '2019-01-01 15:28:58')` returns 27.
* The result is positive if timestamp1 is earlier than timestamp2, and negative if timestamp1 is later than timestamp2.
* Returns NULL if one of the arguments is NULL.

== Examples

----
MINUTES_BETWEEN(TIMESTAMP '2019-01-01 15:00:59',TIMESTAMP '2019-01-01 15:28:59') returns 28
MINUTES_BETWEEN(TIMESTAMP '2019-01-01 15:00:59',TIMESTAMP '2019-01-02 15:00:59') returns 1440
----
