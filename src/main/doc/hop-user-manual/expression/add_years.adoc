= ADD_YEARS

Adds or subtracts a specified number of years to a date or timestamp.

== Syntax

----
ADD_YEARS( date, years )
----

== Arguments

date:: The date or timestamp to modify.
years:: The number of years to add. A negative number subtracts years.

== Returns

Date

== Usage

* If years has a decimal part, it is truncated before the addition.
* A year beyond 9999 is supported, but a result out of the supported range of dates raises an error.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ADD_YEARS(DATE '2019-01-15', 1) returns DATE '2020-01-15'
ADD_YEARS(DATE '2020-02-29', 1) returns DATE '2021-02-28'
----
