= REDUCE

Reduces the elements of an array to a single value, with a lambda evaluated for each element with the result of the previous element.

== Syntax

----
REDUCE( array, (accumulator, element) -> expression [, initial_value] )
----

== Arguments

array:: The source array.
(accumulator, element) -> expression:: A xref:expression.adoc#lambda[lambda] evaluated for each element of the array, the first parameter is the result of the expression for the previous element, the second parameter is the element.
initial_value:: The value of the accumulator for the first element (optional).

== Returns

The data type of the initial value if specified, otherwise the data type of the elements of the array.

== Usage

* The elements are processed in their order.
* With an initial value, the lambda is evaluated for each element and the accumulator has the data type of the initial value.
* Without initial value, the accumulator starts with the first element and the lambda is evaluated from the second element.
* The expression must return a value of the data type of the accumulator: use an initial value to return another data type than the elements.
* A NULL element is passed to the lambda like any other element.
* Returns the initial value if the array is empty, or NULL without initial value.
* Returns NULL if the array is NULL.

== Examples

----
REDUCE([1,2,3], (acc, x) -> acc + x) returns 6
REDUCE([1,2,3], (acc, x) -> acc + x, 100) returns 106
REDUCE([1,2,3], (acc, x) -> acc + x * 0.5, CAST(0 AS NUMBER)) returns 3
REDUCE([3,7,5], (acc, x) -> GREATEST(acc, x)) returns 7
REDUCE(['a','b','c'], (acc, s) -> acc || '-' || s) returns 'a-b-c'
REDUCE([1,2,3], (acc, x) -> acc || x, '') returns '123'
REDUCE([1,NULL,3], (acc, x) -> acc + COALESCE(x, 0)) returns 4
----
