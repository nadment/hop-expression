= FILTER

Returns an array of the elements of an array for which a lambda condition is TRUE.

== Syntax

----
FILTER( array, parameter -> condition )
----

== Arguments

array:: The source array.
parameter -> condition:: A xref:expression.adoc#lambda[lambda] evaluated for each element of the array, the parameter is the element.

== Returns

Array of the data type of the source array.

== Usage

* The elements keep their order.
* An element is kept only if the condition is TRUE, not if it is FALSE or NULL.
* Returns NULL if the array is NULL.

== Examples

----
FILTER([1,-2,3], x -> x > 0) returns [1,3]
FILTER(['a','bb','ccc'], s -> LENGTH(s) > 1) returns ['bb','ccc']
FILTER([1,NULL,3], x -> x > 1) returns [3]
ARRAY_TO_STRING(FILTER(STRING_TO_ARRAY('a,,b',','), s -> s <> ''), ',') returns 'a,b'
----
