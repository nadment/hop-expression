= ADD_NANOSECONDS

Adds or subtracts a specified number of nanoseconds to a date or timestamp.

== Syntax

----
ADD_NANOSECONDS( timestamp, nanoseconds )
----

== Arguments

timestamp:: The date or timestamp to modify.
nanoseconds:: The number of nanoseconds to add. A negative number subtracts nanoseconds.

== Returns

Date

== Usage

* If nanoseconds has a decimal part, it is truncated before the addition.
* A year beyond 9999 is supported, but a result out of the supported range of dates raises an error.
* Returns NULL if one of the arguments is NULL.
