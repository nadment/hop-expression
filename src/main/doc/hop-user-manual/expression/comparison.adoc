== Comparison rules

* Both expressions must be of the same data type family, the comparison is the same whatever the order of the expressions:
** Numbers: an Integer is compared with a Number by value, for example `2 = 2.000` returns TRUE.
** Booleans: FALSE is less than TRUE. A boolean is not comparable with a number, use an explicit cast if needed, for example `CAST(TRUE AS INTEGER) = 1` returns TRUE.
** Strings: the comparison is case-sensitive and uses the Unicode code point of the characters, trailing spaces are significant, for example `'a' = 'a '` returns FALSE.
** Dates: two timestamps are compared as instants on the time line, for example `TIMESTAMP '2022-03-01 8:00:00 -8:00' = TIMESTAMP '2022-03-01 11:00:00 -5:00'` returns TRUE.
** Intervals: a day is 24 hours and a month is 30 days, for example `INTERVAL 1 MONTH = INTERVAL 30 DAYS` returns TRUE.
** Binaries: the bytes are compared one by one.
** JSON and INET values can only be compared with the `=` and `<>` operators.
* A string literal is converted to the data type of the other expression, whatever the order of the expressions, for example `FIELD_DATE >= '2020-01-01'` or `1 = '1'`. An error is raised if the literal can't be converted, for example `'abc' = 1`.
* Other combinations raise an error, a string expression that is not a literal is not implicitly converted to a number or a date, use an explicit cast if needed, for example `FIELD_STRING::INTEGER = 1`.
* Two arrays are comparable if their elements are comparable, an array is not comparable with a value of another data type:
** Two arrays are equal if they have the same number of elements and their elements are equal in the same order, for example `[1,2] = [1.0,2.0]` returns TRUE and `[1,2] = [2,1]` returns FALSE. Two NULL elements are equal.
** Two arrays are ordered element by element, the first different element gives the result, for example `[1,2,3] < [1,3]` returns TRUE. A NULL element is greater than any other element.
** If all the elements are equal, the array with fewer elements is the lesser, for example `[1,2] < [1,2,0]` returns TRUE.
