= CRC32

Calculates a cyclic redundancy check (CRC) value using the Castagnoli polynomial.

== Syntax

----
CRC32( value )
----

== Arguments

value:: A string or binary expression.

== Returns

String

== Usage

* The checksum is based on the CRC-32C polynomial.
* The result is returned as a hex-encoded string of 8 characters, in lower case, with the leading zeros.
* A string is hashed in UTF-8, and a value of another data type, such as a number or a date, is hashed as its text.
* Returns NULL if the argument is NULL.

== Examples

----
CRC32('Apache Hop') returns 'dbb81b5e'
----
