= HOURS_BETWEEN

Returns the number of complete hours between two timestamps.

== Syntax

----
HOURS_BETWEEN( timestamp1, timestamp2 )
----

== Returns

Integer

== Usage

* Only complete hours are counted.
* If timestamp1 is later than timestamp2, the result is negative.
* Returns NULL if one of the arguments is NULL.

== Examples

----
HOURS_BETWEEN(TIMESTAMP '2019-01-01 15:00:59',TIMESTAMP '2019-01-01 15:28:59') returns 0
HOURS_BETWEEN(TIMESTAMP '2019-01-01 15:00:59',TIMESTAMP '2019-01-02 15:00:59') returns 24
----
