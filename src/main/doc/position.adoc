= POSITION

Returns the position of the first character of the first occurrence of a substring in a string.

== Syntax

----
POSITION( substring IN string )
----

== Returns

Integer

== Usage

* The first position in the string is 1.
* If substring is not found in string, the function returns 0.
* Equivalent to xref:instr.adoc["INSTR",role=fun]( string, substring ).
* Returns NULL if one of the arguments is NULL.

== Examples

----
POSITION('def' IN 'abcdefgh') returns 4
POSITION('XYZ' IN 'abcdefgh') returns 0
----

* xref:instr.adoc["INSTR",role=fun]
