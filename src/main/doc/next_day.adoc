= NEXT_DAY

Returns the date of the first specified day of week that occurs after the input date.

== Syntax

----
NEXT_DAY( date, weekday )
----

== Arguments

date:: The input date.
weekday:: The full English name of the day of the week (`'monday'`, `'tuesday'`, ...), case-insensitive.

== Returns

Date

== Usage

* Fails if weekday is not the name of a day of the week.
* Returns NULL if one of the arguments is NULL.

== Examples

----
NEXT_DAY(DATE '2021-06-15', 'Friday') returns DATE '2021-06-18'
NEXT_DAY(DATE '2020-02-28','monday') returns DATE '2020-03-02'
----
