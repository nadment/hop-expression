= TO_CHAR

Converts a numeric, date, binary or boolean value to a string.

== Syntax

----
TO_CHAR( numeric [, format ] )
TO_CHAR( date [, format ] )
TO_CHAR( binary [, format ] )
TO_CHAR( boolean )
TO_CHAR( string )
----

== Arguments

numeric | date | binary | boolean | string:: The value to convert.
format:: The format of the returned string. The supported formats depend on the type of the value to convert and are described below.

== Returns

String

== Usage

* For a numeric value, the default format is `TM`.
* For a date, the default format is defined by the variable `EXPRESSION_DATE_FORMAT`.
* For a binary value, format is `HEX`, `BASE64`, `UTF-8` or `UTF8` (case-insensitive). The default is `HEX`; it can be changed with the variable `EXPRESSION_BINARY_FORMAT`.
* A boolean is converted to `TRUE` or `FALSE`.
* A string is returned unchanged.
* Returns NULL if the value to convert is NULL.

== Examples

----
TO_CHAR(0.45) returns '0.45'
TO_CHAR(12923,'99,999.00') returns ' 12,923.00'
TO_CHAR(12,'FMB0999') returns '0012'
----
