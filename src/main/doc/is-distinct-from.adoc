= IS DISTINCT FROM

Checks whether two expressions are different, treating NULL as a known value for the comparison.

== Syntax

----
expression1 IS [ NOT ] DISTINCT FROM expression2
----

== Returns

Boolean

== Usage

* The operator is NULL-safe: it treats NULL as a known value when comparing, so it never returns NULL.
* This is different from the comparison operator xref:equal.adoc["=",role=op], which treats NULL as an unknown value.
