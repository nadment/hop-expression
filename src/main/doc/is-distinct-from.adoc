= IS DISTINCT FROM

Checks whether two expressions are different, treating NULL as a known value for the comparison.

== Syntax

----
expression1 IS [ NOT ] DISTINCT FROM expression2
----

== Returns

Boolean

== Usage

* The operator is NULL-safe: it treats NULL as a known value when comparing, so it never returns NULL.
* This is different from the comparison operator xref:equal.adoc["=",role=op], which treats NULL as an unknown value.
* The data types are converted as for the comparison operator xref:equal.adoc["=",role=op], and an error is raised if they cannot be compared, for example a date and a number.

== Examples

----
1 IS DISTINCT FROM 1 returns FALSE
1 IS DISTINCT FROM 2 returns TRUE
1 IS DISTINCT FROM NULL returns TRUE
NULL IS DISTINCT FROM NULL returns FALSE
NULL IS NOT DISTINCT FROM NULL returns TRUE
----
