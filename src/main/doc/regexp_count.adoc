= REGEXP_COUNT

Returns the number of times a regular expression pattern occurs in a string.

== Syntax

----
REGEXP_COUNT( source, pattern [, position [, parameters ] ] )
----

== Arguments

source:: The string to search.
pattern:: The regular expression pattern.
position:: The position in source where the search starts. The default value is 1.
parameters:: A string of one or more letters that indicate how the function matches the pattern.
* `c` Case-sensitive matching.
* `i` Case-insensitive matching.
* `m` Multi-line mode.
* `n` Allows the period (`.`), which is the match-any-character character, to match the newline character.

== Returns

Integer

== Usage

* The pattern is defined according to the Java language regular expression rules.
* If no match is found, the function returns 0.
* Raises an error if position is less than 1, returns 0 if position is beyond the end of source.
* An empty pattern matches nothing.
* Returns NULL if source is NULL.

== Examples

----
REGEXP_COUNT('An apple costs 50 cents, a banana costs 10 cents.', '\d+') returns 2
REGEXP_COUNT('An apple costs 50 cents, a banana costs 10 cents.', '\d+', 20) returns 1
REGEXP_COUNT('An apple costs 50 cents, a banana costs 10 cents.', 'CENTS', 1, 'i') returns 2
----
