= TO_BOOLEAN, TRY_TO_BOOLEAN

Converts a string or a numeric value to a Boolean value.

== Syntax

----
TO_BOOLEAN( { string | numeric } )
TRY_TO_BOOLEAN( { string | numeric } )
----

== Returns

Boolean

== Usage

* The strings `'true'`, `'t'`, `'yes'`, `'y'`, `'on'` and `'1'` are converted to TRUE.
* The strings `'false'`, `'f'`, `'no'`, `'n'`, `'off'` and `'0'` are converted to FALSE.
* The conversion of a string is case-insensitive, and the leading and trailing spaces are ignored.
* The numeric value 0 is converted to FALSE.
* All non-zero numeric values are converted to TRUE.
* If the conversion is not possible, which is the case for all other strings, `TO_BOOLEAN` raises an error and `TRY_TO_BOOLEAN` returns NULL.
* Returns NULL if the argument is NULL.

== Examples

----
TO_BOOLEAN('no') returns FALSE
TO_BOOLEAN(2) returns TRUE
----
