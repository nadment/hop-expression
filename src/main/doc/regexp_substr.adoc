= REGEXP_SUBSTR

Returns the substring that matches a regular expression within a string.

== Syntax

----
REGEXP_SUBSTR( source, pattern [, position [, occurrence [, parameters ] ] ] )
----

== Arguments

source:: The string to search.
pattern:: The regular expression pattern.
position:: The position in source where the search starts. The default value is 1.
occurrence:: The occurrence of the pattern to match. The default is the first occurrence.
parameters:: A string of one or more letters that indicate how the function matches the pattern.
* `c` Case-sensitive matching.
* `i` Case-insensitive matching.
* `m` Multi-line mode.
* `n` Allows the period (`.`), which is the match-any-character character, to match the newline character.

== Returns

String

== Usage

* The pattern is defined according to the Java language regular expression rules. The POSIX bracket expressions like `[:alnum:]` are not supported, use the Java classes like `\p{Alnum}`.
* If no match is found, the function returns NULL.
* An empty pattern matches nothing.
* Raises an error if position or occurrence is less than 1.
* A NULL position, occurrence or parameters argument is treated as its default value.
* Returns NULL if source or pattern is NULL.

== Examples

----
REGEXP_SUBSTR('email@apache.org', '@[^.]*') returns '@apache'
REGEXP_SUBSTR('This is a regexp_substr demo', '[a-zA-Z0-9_]+', 1, 4) returns 'regexp_substr'
----
