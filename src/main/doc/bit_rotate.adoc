= BIT_ROTATE

Rotates the bits of an integer value by the specified number of bits to the left or to the right.

== Syntax

----
BIT_ROTATE( value, distance )
----

== Arguments

value:: This expression must evaluate to a data type that can be cast to Integer.
distance:: The number of bits to rotate. A positive distance rotates to the left, a negative distance rotates to the right.

== Returns

Integer

== Usage

* Returns NULL if one of the arguments is NULL.

== Examples

----
BIT_ROTATE(1,4) returns 16
BIT_ROTATE(16,-4) returns 1
----
