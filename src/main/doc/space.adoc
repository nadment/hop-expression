= SPACE

Returns a string consisting of the specified number of space characters.

== Syntax

----
SPACE( length )
----

== Returns

String

== Usage

* Returns NULL if the argument is negative.
* Fails if length is greater than 32672.
* Returns NULL if the argument is NULL.

== Examples

----
SPACE(4) returns '    '
SPACE(0) returns ''
SPACE(-3) returns NULL
----
