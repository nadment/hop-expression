= CURRENT_DATE, TODAY

Returns the current date in the context time zone (system time zone by default).

== Syntax

----
CURRENT_DATE()
----

The `TODAY` function provides alternative syntax.

----
TODAY()
----

== Returns

Date

== Usage

* Always returns the same value within an execution context, such as a running pipeline.
* The `CURRENT_TIMESTAMP` function is similar but returns the date and time.
