= MOD, %

Returns the remainder of the division of the dividend by the divisor.

== Syntax

----
MOD( dividend, divisor )
----

The xref:mod.adoc["%",role=op] operator provides alternative syntax.

----
dividend % divisor
----

== Arguments

dividend:: The numeric value to divide.
divisor:: The numeric value by which to divide.

== Returns

Number

== Usage

* The result has the same sign as dividend.
* Fails with a division by zero error if divisor is 0.
* A boolean or a string is not implicitly converted to a number, use an explicit cast if needed.
* Returns NULL if one of the arguments is NULL.

== Examples

----
MOD(16,5) returns 1
MOD(11,4) returns 3
MOD(-11,4) returns -3
MOD(11,-4) returns 3
MOD(11.3,4) returns 3.3
11 % 4 returns 3
----
