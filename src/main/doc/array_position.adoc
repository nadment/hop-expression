= ARRAY_POSITION

Returns the position of the first occurrence of an element in an array, optionally starting the search at a specified position.

== Syntax

----
ARRAY_POSITION( array, element [, start ] )
----

== Arguments

array:: The array to search.
element:: The element to search for within the array.
start:: The position, inclusive, at which the search starts. The default is 1.

== Returns

Integer

== Usage

* The first position in the array is 1.
* Returns 0 if the element is not found in the array.
* Returns NULL if one of the arguments is NULL.

== Examples

----
ARRAY_POSITION(['sun','mon','tue','wed','thu','fri','sat'],'mon') returns 2
ARRAY_POSITION([1,2,3],4) returns 0
ARRAY_POSITION([1,2,3],2,10) returns 0
----
