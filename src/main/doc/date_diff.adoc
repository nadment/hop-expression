= DATE_DIFF

Returns the number of complete time units between two dates or timestamps.

== Syntax

----
DATE_DIFF( unit, start_date, end_date )
----

== Arguments

unit:: The time unit of the result. Supported units:
* `MILLENNIUM`
* `CENTURY`
* `DECADE`
* `YEAR`
* `MONTH`
* `QUARTER`
* `WEEK`
* `DAY`
* `HOUR`
* `MINUTE`
* `SECOND`
* `MILLISECOND`
* `MICROSECOND`
* `NANOSECOND`

start_date:: The start date or timestamp.
end_date:: The end date or timestamp.

== Returns

Integer

== Usage

* The result is negative if end_date is earlier than start_date.
* Raises an arithmetic overflow error if the number of units exceeds the integer range, for example more than about 292 years in nanoseconds.
* The unit cannot be NULL. Returns NULL if one of the other arguments is NULL.

== Examples

----
DATE_DIFF(DAY, DATE '2023-02-01', CURRENT_DATE())
DATE_DIFF(DAY, DATE '2021-11-09',DATE '2020-12-28') returns -316
DATE_DIFF(YEAR, DATE '2022-12-31',DATE '2024-06-01') returns 1
----
