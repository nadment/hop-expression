= STRTOK

Splits a string on the specified list of delimiter characters and returns the part at the specified position.

== Syntax

----
STRTOK( string [, delimiters ] [, part ] )
----

== Arguments

string:: The string to split into tokens.
delimiters:: A string in which each character is a delimiter. If not specified, the default is a space character.
part:: The position of the token to return, starting at 1. If not specified, the default is 1.

== Returns

String

== Usage

* The string is split into at most 256 tokens.
* If string starts or ends with a delimiter, the empty string before or after that delimiter is a valid token.
* Adjacent delimiters are treated as delimiters for empty tokens.
* If part is negative, the tokens are counted backward from the end of the string.
* Returns NULL if the requested token does not exist.
* Returns NULL if one of the arguments is NULL.

TIP: Use the `SQUEEZE` function to remove the leading, trailing and adjacent space delimiters.

== Examples

----
STRTOK('AAA BBB CCC DDD') returns 'AAA'
STRTOK('AAA BBB CCC DDD',3) returns 'CCC'
STRTOK('AAA.BBB:CCC-DDD','.-:',2) returns 'BBB'
STRTOK('127.1-2-3','.-:',-1) returns '3'
STRTOK('127.1.2.3','.',5) returns NULL
----
