= TRIM

Removes the leading and trailing characters from a string.

== Syntax

----
TRIM( string [, characters ] )
----

== Arguments

string:: The string to trim.
characters:: One or more characters to remove from both sides of the string, specified in any order. If not specified, the whitespace characters are removed.

== Returns

String

== Usage

* The whitespace characters are the Java whitespace characters, which do not include the no-break space `CHR(160)`.
* Returns NULL if one of the arguments is NULL.

== Examples

----
TRIM('  a b  ') returns 'a b'
TRIM(' 01ABC10 ', ' 012') returns 'ABC'
----
