= IFNULL, NVL

Returns the first expression if it is not NULL, otherwise the second expression.

== Syntax

----
IFNULL( expression1, expression2 )
----

The `NVL` function is an alias.

----
NVL( expression1, expression2 )
----

== Returns

The data type of the returned value is the common data type of expression1 and expression2.

== Usage

* Returns NULL only if all arguments are NULL.

== Examples

----
IFNULL('A','B') returns 'A'
----
