= HEX_DECODE

Decodes a hexadecimal string to a string.

== Syntax

----
HEX_DECODE( string )
----

== Returns

String

== Usage

* Raises an error if the string has an odd number of characters or a character that is not a hexadecimal digit.
* Returns NULL if the argument is NULL.

== Examples

----
HEX_DECODE('41706163686520486f70') returns 'Apache Hop'
----
