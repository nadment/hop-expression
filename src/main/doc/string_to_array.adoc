= STRING_TO_ARRAY

Splits a string into an array of strings based on the specified delimiter.

== Syntax

----
STRING_TO_ARRAY( string, delimiter )
----

== Arguments

string:: The string to split.
delimiter:: The string that separates the elements.

== Returns

Array

== Usage

* If delimiter is an empty string `''`, the result is an array containing the entire string as a single element.
* Empty elements between two delimiters, or at the beginning or end of the string, are kept.
* Returns NULL if one of the arguments is NULL.

== Examples

----
STRING_TO_ARRAY('blue|orange|yellow','|') returns ['blue','orange','yellow']
STRING_TO_ARRAY('blue|orange|yellow','') returns ['blue|orange|yellow']
STRING_TO_ARRAY('a||b','|') returns ['a','','b']
----
