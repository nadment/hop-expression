= SIN

Calculates the trigonometric sine of an angle expressed in radians.

== Syntax

----
SIN( numeric )
----

== Returns

Number

== Usage

* The argument is an angle expressed in radians.
* Returns a value in the range [-1, 1].
* Returns NULL if the argument is NULL.

== Examples

----
SIN(0) returns 0
SIN(PI()/2) returns 1
----
