= DECODE

Compares an expression to each search value in order and returns the result associated with the first search value that matches.

== Syntax

----
DECODE( expression, search1, result1 [, search2, result2... ] [, default ] )
----

== Arguments

expression:: The expression to compare to the search values.
searchN:: The search values to compare to expression.
resultN:: The value returned if expression matches the search value searchN.
default:: The optional value returned if no search value matches expression.

== Returns

The data type of the returned value is the data type of result1.

== Usage

* If no search value matches expression, default is returned, or NULL if default is omitted.

TIP: Contrary to `CASE`, a NULL expression matches a NULL search value.

== Examples

----
DECODE(EXTRACT(ISODAYOFWEEK FROM CURRENT_DATE()),
1, 'Monday',
2, 'Tuesday',
3, 'Wednesday',
4, 'Thursday',
5, 'Friday',
6, 'Saturday',
7, 'Sunday')
----
