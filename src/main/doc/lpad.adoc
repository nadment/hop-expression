= LPAD

Left-pads a string with characters from another string, or left-pads a binary value with bytes from another binary value.

== Syntax

----
LPAD( value, length [, pad ] )
----

== Arguments

value:: String or binary value to pad.
length:: Length of the result, in characters for a string or in bytes for a binary value.
pad:: String or binary value used for padding. If pad is omitted, the function pads with spaces for a string or with 0x00 for a binary value.

== Returns

String or Binary

== Usage

* Both value and pad must be of the same string or binary type.
* The data type of the returned value is the same as the data type of value.
* If pad is omitted or NULL, the function pads with spaces for a string or with `0x00` for a binary.
* If length is smaller than the length of value, the function truncates value to length.
* If pad is empty, value is not padded but is still truncated.
* If length is negative, the function returns an empty string or binary.
* Fails if length is greater than 32672 for a string, or 16777216 (16 MB) for a binary.
* Returns NULL if value or length is NULL.

== Examples

----
LPAD('123',5,'*') returns '**123'
----
