= DAYS_BETWEEN

Returns the number of complete days between two dates or timestamps.

== Syntax

----
DAYS_BETWEEN( date1, date2 )
----

== Returns

Integer

== Usage

* The result is negative if date2 is earlier than date1.
* Returns NULL if one of the arguments is NULL.

== Examples

----
DAYS_BETWEEN(DATE '2007-11-09',DATE '2007-12-09') returns 30
DAYS_BETWEEN(DATE '2021-11-09',DATE '2020-12-28') returns -316
----
