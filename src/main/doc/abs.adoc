= ABS

Returns the absolute (positive) value of a number or an interval.

== Syntax

----
ABS( value )
----

== Returns

The data type of the returned value is the same as the data type of the argument (Integer, Number or Interval).

== Usage

* Raises an error if the result is out of the integer range: the absolute value of -9223372036854775808 is greater than the largest integer. Cast the argument to NUMBER to avoid it.
* Returns NULL if the argument is NULL.

== Examples

----
ABS(-123) returns 123
ABS(INTERVAL -5 YEARS) returns INTERVAL 5 YEARS
----
