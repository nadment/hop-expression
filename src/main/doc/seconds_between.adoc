= SECONDS_BETWEEN

Returns the number of complete seconds between two timestamps.

== Syntax

----
SECONDS_BETWEEN( timestamp1, timestamp2 )
----

== Returns

Integer

== Usage

* Only complete seconds are counted, the fractional seconds are ignored: `SECONDS_BETWEEN(TIMESTAMP '2019-01-01 15:00:00.900',TIMESTAMP '2019-01-01 15:00:01.100')` returns 0.
* The result is positive if timestamp1 is earlier than timestamp2, and negative if timestamp1 is later than timestamp2.
* Returns NULL if one of the arguments is NULL.

== Examples

----
SECONDS_BETWEEN(TIMESTAMP '2019-01-01 15:00:59',TIMESTAMP '2019-01-02 15:00:59') returns 86400
----
