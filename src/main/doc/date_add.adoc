= DATE_ADD

Adds a number of time units to a date or timestamp, or subtracts them if the number is negative.

== Syntax

----
DATE_ADD( unit, value, date )
----

== Arguments

unit:: The time unit of value. Supported units:
* `YEAR`
* `QUARTER`
* `MONTH`
* `WEEK`
* `DAY`
* `HOUR`
* `MINUTE`
* `SECOND`
* `NANOSECOND`

value:: The integer number of units to add. A negative value subtracts the units.
date:: The date or timestamp to modify.

== Returns

Date

== Usage

* Any other unit raises an error.
* A year beyond 9999 is supported, but a result out of the supported range of dates raises an error.
* The unit cannot be NULL. Returns NULL if one of the other arguments is NULL.

== Examples

----
DATE_ADD(DAY, 5, DATE '2023-02-01') returns DATE '2023-02-06'
DATE_ADD(MONTH,3,DATE '2019-11-15') returns DATE '2020-02-15'
DATE_ADD(WEEK,-3,DATE '2019-01-15') returns DATE '2018-12-25'
----
