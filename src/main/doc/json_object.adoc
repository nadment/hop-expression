= JSON_OBJECT

Generates a JSON object from the specified key-value pairs.

== Syntax

----
JSON_OBJECT( [ KEY ] key1 VALUE value1 [, [ KEY ] key2 VALUE value2... ] )
----

== Returns

Json

== Usage

* The returned JSON object contains all the key-value pairs.
* The keyword `KEY` is optional and is provided for semantic clarity.
* If several pairs have the same key, the last one is retained in the returned object.

== Examples

----
JSON_OBJECT(KEY 'first' VALUE 'John', KEY 'last' VALUE 'Doe')
JSON_OBJECT(KEY 'name' VALUE 'Smith') returns {"name":"Smith"}
----
