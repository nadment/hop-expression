= DIFFERENCE

Compares the `SOUNDEX` values of two strings and returns an integer that measures their similarity.

== Syntax

----
DIFFERENCE( string1, string2 )
----

== Returns

Integer between 0 and 4

== Usage

* The result is the number of leading characters that the `SOUNDEX` values have in common, on a scale of 0 to 4. For example, `DIFFERENCE('Robert','Bobert')` returns 0, as their `SOUNDEX` values R163 and B163 differ on the first character.
* A value of 0 indicates a weak or no similarity between the `SOUNDEX` values; a value of 4 indicates that the `SOUNDEX` values are extremely similar, or even identical.
* Returns 0 if one of the strings has no letter, as its `SOUNDEX` value is empty.
* The diacritic marks are removed first, like `SOUNDEX` does: `DIFFERENCE('Émile','Emile')` returns 4.
* Raises an error naming the letter if one of the strings contains a letter that is not a Latin letter, such as a Greek letter, like `SOUNDEX` does.
* Returns NULL if one of the arguments is NULL.

== Examples

----
DIFFERENCE('Juice', 'Jucy') returns 4
DIFFERENCE('Apple', 'Orange') returns 0
----
