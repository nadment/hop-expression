= MAKE_INTERVAL

Creates an interval from individual numeric components.

== Syntax

----
MAKE_INTERVAL( year, month, day, hour, minute, second )
----

The interval literal provides an alternative syntax.

----
INTERVAL '3 years 6 months'
----

== Arguments

year:: The number of years.
month:: The number of months.
day:: The number of days.
hour:: The number of hours.
minute:: The number of minutes.
second:: The number of seconds, with an optional fractional part (for example `59.123`).

== Returns

Interval

== Usage

* An interval can be added to or subtracted from a date or timestamp.
* Each value can be negative, the years and months are summed into a year-month part, and the days, hours, minutes and seconds into a day-time part, for example `MAKE_INTERVAL(0,0,1,-1,0,0)` returns 23 hours.
* An error is raised if the year-month part and the day-time part have opposite signs, for example `MAKE_INTERVAL(1,0,-1,0,0,0)`, or if a part is out of the supported range.
* Returns NULL if one of the arguments is NULL.

== Examples

----
MAKE_INTERVAL(20,1,1,23,15,59.123) returns INTERVAL '+20-1 1 23:15:59.123'
----
