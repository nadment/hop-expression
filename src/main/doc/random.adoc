= RANDOM, RAND

Returns a random number between 0 (inclusive) and 1 (exclusive).

== Syntax

----
RANDOM( [ seed ] )
----

The `RAND` function is an alias and provides alternative syntax.

----
RAND( [ seed ] )
----

== Arguments

seed:: An integer used to initialize the random number generator.

== Returns

Number

== Usage

* If seed is specified, the function returns a repeatable sequence of random numbers.
* If seed is omitted, the function returns a completely random number.
* Fails if seed is NULL, is not an integer or is not a constant.

== Examples

----
RANDOM()
----
