= TO_JSON, TRY_TO_JSON

Converts a string to a Json value.

== Syntax

----
TO_JSON( string )
TRY_TO_JSON( string )
----

== Returns

Json

== Usage

* If the conversion is not possible, `TO_JSON` raises an error and `TRY_TO_JSON` returns NULL.
* An empty or blank string is not a valid JSON.
* Returns NULL if the argument is NULL.
