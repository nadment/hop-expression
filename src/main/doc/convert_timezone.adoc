= CONVERT_TIMEZONE

Converts a timestamp to another time zone.

== Syntax

----
CONVERT_TIMEZONE( [ source_timezone, ] target_timezone, timestamp )
----

== Arguments

source_timezone:: The time zone in which timestamp is interpreted. If omitted, the time zone of timestamp is used.
target_timezone:: The time zone to which timestamp is converted.
timestamp:: The timestamp to convert.

== Returns

Date

== Usage

* Time zone names are case-sensitive and must be enclosed in single quotes (e.g. `'UTC'`).
* Raises an error if a time zone is not valid.
* Returns NULL if timestamp is NULL.

== Examples

----
CONVERT_TIMEZONE('Europe/Paris',TIMESTAMP '2020-05-25 20:48:00') returns TIMESTAMP '2020-05-25 22:48:00' AT TIME ZONE 'Europe/Paris'
CONVERT_TIMEZONE('Europe/Paris','Asia/Tokyo',TIMESTAMP '2020-05-25 20:48:00') returns TIMESTAMP '2020-05-26 03:48:00' AT TIME ZONE 'Asia/Tokyo'
----
