= IS_DATE

Checks whether a value is a valid date or timestamp in the specified format.

== Syntax

----
IS_DATE( value, format )
----

== Arguments

value:: Value to check.
format:: Date format used to parse a string value, as in xref:to_date.adoc["TO_DATE",role=fun].

== Returns

Boolean

== Usage

* Returns TRUE if value is a date or a timestamp that is not NULL.
* Returns FALSE if the data type of value is neither a string nor a date or timestamp.
* Returns FALSE if value or format is NULL.
* Raises an error if format is not a valid date format.

== Examples

----
IS_DATE( INVOICE_DATE, 'YYYY-MM-DD' )
IS_DATE('2023-04-25','YYYY-MM-DD') returns TRUE
IS_DATE('2023-02-31','YYYY-MM-DD') returns FALSE
----
