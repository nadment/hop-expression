= TO_BINARY, TRY_TO_BINARY

Converts a string to a binary value.

== Syntax

----
TO_BINARY( string [, format ] )
TRY_TO_BINARY( string [, format ] )
----

== Arguments

string:: The string to convert.
format:: The format of the string: `HEX`, `BASE64`, `UTF-8` or `UTF8`. The value is case-insensitive. The default is `HEX`; it can be changed with the variable `EXPRESSION_BINARY_FORMAT`.

== Returns

Binary

== Usage

* If the conversion is not possible, `TO_BINARY` raises an error and `TRY_TO_BINARY` returns NULL.
* Returns NULL if string is NULL.

include::binaryformat.adoc[]

== Examples

----
TO_BINARY('41706163686520486f70') returns BINARY '41706163686520486f70'
TO_BINARY('QXBhY2hlIEhvcA==','BASE64') returns BINARY '41706163686520486f70'
----
