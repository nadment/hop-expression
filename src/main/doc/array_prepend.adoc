= ARRAY_PREPEND

Returns a new array with an element added at the beginning of an array.

== Syntax

----
ARRAY_PREPEND( element, array )
----

The xref:concat.adoc["||",role=op] operator provides an alternative syntax.

----
element || array
----

== Arguments

element:: The element to prepend to the array.
array:: The array to prepend to.

== Returns

Array

== Usage

* The data type of element must be compatible with the data type of the elements of array.
* Returns NULL if the array is NULL.

== Examples

----
ARRAY_PREPEND(0,[1,2,3]) returns [0,1,2,3]
ARRAY_PREPEND('sun',['mon','tue']) returns ['sun','mon','tue']
----
