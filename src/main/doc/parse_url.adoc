= PARSE_URL

Returns the specified part of the URL or the value for the specified QUERY key.

== Syntax

----
PARSE_URL( url, part [, key ] )
----

== Arguments

url:: The URL to parse.
part:: The part of the URL to return, in upper case.
* `HOST`
* `PORT`
* `PATH`
* `QUERY`
* `REF`
* `PROTOCOL`
* `AUTHORITY`
* `FILE`
* `USERINFO`
key:: The key of the query parameter whose value is returned (case-sensitive). It can only be used with the `QUERY` part: with another part, the function returns NULL.

== Returns

String

== Usage

* If the requested part or key is not found, the function returns NULL.
* If part is not one of the allowed values, or if url is not a valid URI reference (for example if it contains a space), the function returns NULL. The part is case-sensitive and must be in upper case.
* A relative reference without protocol is accepted: `PARSE_URL('abc','PATH')` returns 'abc'.
* The `FILE` part is the path and the query, without the fragment. It is an empty string if the URL has neither path nor query, and starts with `?` if the URL has a query but no path.
* If a key appears several times in the query, the first value is returned.
* Returns NULL if one of the arguments is NULL.

== Examples

----
PARSE_URL('https://hop.apache.org:80/path?id=1','HOST') returns 'hop.apache.org'
PARSE_URL('https://hop.apache.org:80/path?id=1','PATH') returns '/path'
PARSE_URL('https://hop.apache.org:80/path?id=1&lang=fr','FILE') returns '/path?id=1&lang=fr'
PARSE_URL('https://hop.apache.org:80/path?id=1&lang=fr','QUERY') returns 'id=1&lang=fr'
PARSE_URL('https://hop.apache.org:80/path?id=1&lang=fr','QUERY','id') returns '1'
PARSE_URL('https://hop.apache.org:80/path?query=1#fragment','REF') returns 'fragment'
----
