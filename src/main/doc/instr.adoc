= INSTR

Returns the position of the first character of the specified occurrence of a substring in a string.

== Syntax

----
INSTR( string, substring [, position [, occurrence ] ] )
----

== Arguments

string:: String to search in.
substring:: String to search for.
position:: Position where the search starts. If position is negative, the function counts back that number of characters from the end of string and then searches towards the beginning of string. The default is 1.
occurrence:: Occurrence of substring to search for. The value must be positive. The default is 1.

== Returns

Integer

== Usage

* The first position in the string is 1.
* The overlapping occurrences are counted, so `INSTR('AAA','AA',1,2)` returns 2.
* Returns 0 if substring is not found in string, or if position is beyond the start or the end of string.
* Raises an error if position is 0 or if occurrence is less than 1.
* Returns NULL if one of the arguments is NULL.

== Examples

----
INSTR('CORPORATE FLOOR','OR') returns 2
INSTR('CORPORATE FLOOR','OR',3,2) returns 14
INSTR('CORPORATE FLOOR','OR',-3,2) returns 2
----
