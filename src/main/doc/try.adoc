= TRY

Evaluates an expression and returns NULL instead of raising an error for certain types of errors.

== Syntax

----
TRY( expression )
----

== Arguments

expression:: The expression to evaluate.

== Returns

The data type of the returned value is the same as the data type of the expression.

== Usage

* The following errors are handled:
** Division by zero
** Arithmetic overflow
** Date or interval out of the supported range, like `ADD_YEARS(DATE '2020-01-01', 2000000000)`
** Invalid cast or function argument
** Argument value out of range
* Any other error is raised.
* Returns NULL if the argument is NULL.

== Examples

The following calls raise an error without `TRY`. Wrapped in `TRY`, they return NULL.

----
TRY(5/0) returns NULL
TRY('abc'::INTEGER) returns NULL
TRY(LN(0)) returns NULL
----
