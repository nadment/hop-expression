= SHA256

Calculates the SHA-256 hash of a value.

== Syntax

----
SHA256( value )
----

== Arguments

value:: The string or binary value to hash.

== Returns

String

== Usage

* The result is a hex-encoded string of 64 characters (256 bits).
* Returns NULL if the argument is NULL.

== Examples

----
SHA256('Test') returns '532eaabd9574880dbf76b9b8cc00832c20a6ec113d682299550d7a6e0f345e25'
----
