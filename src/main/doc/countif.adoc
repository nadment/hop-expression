= COUNTIF [aggregate]

Returns the number of rows that satisfy the condition over a group of rows.

== Syntax

----
COUNTIF( condition )
----

== Returns

Integer

== Usage

* Only the rows for which condition is TRUE are counted.

NOTE: This is an aggregate function that should only be used in the Aggregate transform.

== Examples

----
COUNTIF(Amount>=1000)
----
