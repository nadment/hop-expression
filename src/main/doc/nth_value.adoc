= NTH_VALUE [aggregate]

Returns the nth value in an ordered set of values over a group of rows.

== Syntax

----
NTH_VALUE( expression, offset ) [ IGNORE NULLS | RESPECT NULLS ]
----

== Arguments

expression:: The expression to evaluate for each row of the group.
offset:: The position of the value to return in the group, starting at 1.

== Returns

The data type of the returned value is the same as the data type of the input values.

== Usage

* If neither `IGNORE NULLS` nor `RESPECT NULLS` is specified, the default is `RESPECT NULLS`.
* With `RESPECT NULLS`, the function returns NULL if the nth value is NULL.
* With `IGNORE NULLS`, NULL values are skipped and the function returns the nth non-NULL value.
* Returns NULL if the group contains fewer than offset values.
* Raises an error if offset is NULL or less than 1.

NOTE: This is an aggregate function that should only be used in the Aggregate transform.

== Examples

----
NTH_VALUE( City, 3 ) IGNORE NULLS
----
