= CONCAT_WS

Concatenates strings or binaries into one, inserting a separator between them.

== Syntax

----
CONCAT_WS( separator, string1 [, string2... ] )
----

== Returns

String or Binary

== Usage

* NULL values in the strings to concatenate are ignored.
* Returns NULL if separator is NULL.

== Examples

----
CONCAT_WS(',','ONE','TWO','THREE') returns 'ONE,TWO,THREE'
CONCAT_WS('--','one') returns 'one'
----
