= AND

Returns TRUE if both boolean expressions are TRUE.

== Syntax

----
boolean1 AND boolean2
----

== Returns

Boolean

== Usage

* A number is converted to a boolean: 0 is FALSE and any other value is TRUE. Other data types like a string raise an error.
* Returns FALSE if one of the arguments is FALSE, even if the other one is NULL.
* Returns NULL if one of the arguments is NULL and the other one is TRUE or NULL.
