= TO_INTERVAL

Converts a string to an interval value.

== Syntax

----
TO_INTERVAL( string )
----

== Returns

Interval

== Usage

* The string uses either the verbose syntax, such as `'1 year 6 months 12 hours'`, or the short syntax, such as `'1-6 0 12:00:00'`.
* The string can start with a `+` or `-` sign; `-` negates the interval. In the short syntax, the days and the time can have their own sign, such as `'+0-1 -1 00:00:00'`, and in the verbose syntax each quantity can have its own sign, such as `'1 month -1 day'`.
* Raises an error if the string is not a valid interval.
* Returns NULL if the argument is NULL.

== Examples

----
TO_INTERVAL('1 year 6 months 12 hours') returns INTERVAL '1-6 0 12:00:00'
TO_INTERVAL('1-6 0 12:00:00') returns INTERVAL '1-6 0 12:00:00'
----
