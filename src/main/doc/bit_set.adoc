= BIT_SET

Returns an integer value with the bit at the specified position set to 1.

== Syntax

----
BIT_SET( value, position )
----

== Arguments

value:: An integer value. A number or a boolean is not implicitly cast to Integer, an explicit cast is required.
position:: The position of the bit to set.

== Returns

Integer

== Usage

* The first bit has position 1.
* Returns value unchanged if position is greater than 64.
* Returns NULL if position is negative or zero.
* Returns NULL if one of the arguments is NULL.

== Examples

----
BIT_SET(16,1) returns 17
BIT_SET(1,4) returns 9
----
