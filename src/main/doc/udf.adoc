= User defined function (UDF)

A user-defined function is a scalar function written by the user as an expression: it takes arguments and returns one output value. It encapsulates a complex or frequently used expression into a reusable function.

A user-defined function is a metadata element of the project, defined by:

* a name, used to call the function (the name is not case-sensitive);
* an optional description;
* a list of arguments, each with a name and a data type;
* a source expression that refers to the arguments by their names.

== Syntax

----
function_name( [ argument1 [, argument2 ...] ] )
----

== Returns

The data type of the returned value is defined by the user-defined function implementation.

== Usage

* A call must provide exactly one value for each argument of the function.
* The source expression can only refer to the arguments of the function, not to the fields of the row.
* The function is expanded where it is called: its arguments are replaced by the values of the call, and the resulting expression is checked and optimized like any other expression.
* No state is retained between function calls.

== Examples

A function `DATE_FROM_ID` with an argument `id` of type `Integer` and the source expression:

----
CASE WHEN id IS NULL THEN NULL ELSE TO_DATE(TO_CHAR(id),'YYYYMMDD') END
----

can be called like any other function:

----
DATE_FROM_ID(20230105)
----
