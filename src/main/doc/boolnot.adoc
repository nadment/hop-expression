= NOT

Returns TRUE if the boolean expression is FALSE, and FALSE if it is TRUE.

== Syntax

----
NOT boolean
----

The function form provides an alternative syntax.

----
NOT( boolean )
----

== Returns

Boolean

== Usage

* Returns NULL if the argument is NULL.
