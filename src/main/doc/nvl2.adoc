= NVL2

Returns one value if the expression is not NULL, and another value if it is NULL.

== Syntax

----
NVL2( expression, value_if_not_null, value_if_null )
----

== Arguments

expression:: The expression to test.
value_if_not_null:: The value returned if expression is not NULL.
value_if_null:: The value returned if expression is NULL.

== Returns

The data type of the returned value is the most general data type of value_if_not_null and value_if_null.

== Usage

* value_if_not_null and value_if_null must have the same (or compatible) data type; expression can be of any data type.

== Examples

----
NVL2('test','ex1','ex2') returns 'ex1'
----
