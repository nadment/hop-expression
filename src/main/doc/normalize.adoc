= NORMALIZE

Returns a string as a normalized string, allowing for easier sorting and searching of text.

== Syntax

----
NORMALIZE( string [, form ] )
----

== Arguments

string:: The string to normalize.
form:: The Unicode normalization form to use for the result. The default form is `NFC`.
* `NFD` Canonical decomposition.
* `NFC` Canonical decomposition, followed by canonical composition.
* `NFKD` Compatibility decomposition.
* `NFKC` Compatibility decomposition, followed by canonical composition.

== Returns

String

== Usage

* Normalization is often used when two strings render the same on the screen but have different Unicode code points.
* Fails if form is not one of the supported forms.
* Returns NULL if string or form is NULL.

== Examples

----
NORMALIZE('i⁹', 'NFKC') returns 'i9'
----
