= LIKE

Checks whether a string matches a pattern, with a case-sensitive comparison.

== Syntax

----
string [ NOT ] LIKE pattern [ ESCAPE escape ]
----

== Arguments

string:: String to compare.
pattern:: Pattern to match, which may contain the following SQL wildcards:
* An underscore `_` matches any single character.
* A percent sign `%` matches any sequence of zero or more characters.
escape:: Single character that instructs the operator to treat the wildcard character that follows it as a regular character. The default escape character is backslash `\`.

== Returns

Boolean

== Usage

* The pattern must match the entire string.
* Returns NULL if string or pattern is NULL.

TIP: Use the xref:ilike.adoc["ILIKE",role=op] operator for a case-insensitive comparison.

== Examples

----
customer_name LIKE 'APA%'
customer_name LIKE '%A#_B%' ESCAPE '#'
'Tuesday' LIKE '%es%' returns TRUE
'ADD_MONTHS' LIKE '%ADD!_%' ESCAPE '!' returns TRUE
----
