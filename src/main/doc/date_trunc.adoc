= DATE_TRUNC

Truncates a date or timestamp to the start of the specified time unit.

== Syntax

----
DATE_TRUNC( unit, date )
----

== Arguments

unit:: The time unit to truncate to. Supported units:
* `MILLENNIUM`
* `CENTURY`
* `DECADE`
* `YEAR`
* `MONTH`
* `QUARTER`
* `WEEK` (synonym `WEEKOFYEAR`)
* `DAY` (synonym `DAYOFMONTH`)
* `HOUR`
* `MINUTE`
* `SECOND`
* `MILLISECOND`
* `MICROSECOND`
* `NANOSECOND`

date:: The date or timestamp to truncate.

== Returns

Date

== Usage

* A week starts on Monday.
* As with xref:extract.adoc["EXTRACT",role=fun], a century or a millennium starts in a year ending with 1: `DATE_TRUNC(CENTURY, DATE '2020-05-08')` returns `DATE '2001-01-01'`.
* Before year 1, the decade, century or millennium is the same as with xref:extract.adoc["EXTRACT",role=fun], so the result is never after the date: the decade -1 starts in year -10 and the century 0 in year -99.
* Raises an error if unit is not supported, for example `ISOWEEK`.
* The unit cannot be NULL. Returns NULL if one of the other arguments is NULL.

== Examples

----
DATE_TRUNC(MONTH, DATE '2020-05-08') returns DATE '2020-05-01'
DATE_TRUNC(WEEK, DATE '2020-05-28') returns DATE '2020-05-25'
----
