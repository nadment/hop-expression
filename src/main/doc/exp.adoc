= EXP

Returns the exponential of a numeric value, that is the number e raised to the power of this value.

== Syntax

----
EXP( numeric )
----

== Returns

Number

== Usage

* Returns a value in the range of (0, &infin;), the result is never 0.
* Returns NULL if the argument is NULL.
